# Dataset Details

## Dataset Used

The project uses the **A Dataset for Detecting Phishing URLs!** dataset from Kaggle.

## Training Dataset

- Total URLs: 7,658
- Legitimate URLs: 3,829
- Phishing URLs: 3,829
- Features: 87
- Missing values: 0

## Testing Dataset

- Total URLs: 3,772
- Legitimate URLs: 1,886
- Phishing URLs: 1,886

## Target Variable

The target column is:

`status`

The two classes are:

- `legitimate`
- `phishing`

## Important Features

Some URL-based features include:

- URL length
- Hostname length
- Number of dots
- Number of hyphens
- Number of `@` symbols
- HTTPS token
- IP address
- Number of subdomains
- URL shortening service
- Phishing hints
- Suspicious TLD
- Domain age
- Web traffic
- Google index
- Page rank

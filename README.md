# Phishing URL Detection Using Machine Learning

A Machine Learning-based web application designed to analyze URL characteristics and classify URLs as **Legitimate** or **Phishing**. This project was developed as part of the **REVA University Abhinava Hackathon**.

---

## 📌 Project Overview

Phishing is a serious cybersecurity threat where attackers use deceptive URLs to redirect users to fraudulent websites and potentially obtain sensitive information.

This project uses **Machine Learning classification techniques** to analyze various URL characteristics and identify patterns commonly associated with phishing attempts.

The system provides an automated method for evaluating URLs and predicting whether they are **legitimate or potentially phishing**.

---

## 🎯 Problem Statement

Phishing URLs can be created, modified, and distributed rapidly, making them difficult to detect using traditional rule-based techniques alone.

The objective of this project is to develop a Machine Learning-based solution that can:

- Analyze important characteristics of a given URL
- Detect patterns commonly associated with phishing URLs
- Classify URLs as legitimate or phishing
- Generate predictions for previously unseen URLs
- Assist users in identifying potentially suspicious URLs

---

## 💡 Proposed Solution

The proposed system uses a **labelled dataset** containing examples of both legitimate and phishing URLs.

Relevant URL-based features are extracted and processed before being supplied to Machine Learning classification models. The models learn patterns from the training data and apply them to classify new and previously unseen URLs.

The system follows a simple workflow:

**URL Input → Feature Analysis → Machine Learning Model → Classification → Prediction**

### 🔍 Prediction Classes

The system provides one of the following classification results:

- 🟢 **LEGITIMATE** – The URL is classified as legitimate based on the analyzed characteristics.
- 🔴 **PHISHING** – The URL contains characteristics commonly associated with phishing activity.

The final prediction is generated by the trained Machine Learning model based on the extracted URL features.

> **Note:** The classification represents the model's prediction based on the available URL features and does not guarantee the absolute safety or security of a website.
